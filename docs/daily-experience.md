# 日常使用体验

本阶段把每日关注事项、可选站内提醒和周复盘作为一个完整交付范围，并合入教学日期提示修复。Web、Windows 和 Android 使用同一套业务页面。源码版本为 `0.1.14`，Android 构建号为 `19`；正式发布状态见 [发布记录](release-0114.md)，不能把页面构建当成安装验收。

## 今日与提醒

所有模式的电脑导航和手机“更多”均提供 `/overview`。这是共享入口，不会改变三种模式的独立工作区，也不会自动改期、完成或移动任务。

事项按所选日期分为今日待完成、已逾期、即将到期；提前范围为 1 至 14 天。周期任务使用补做日期 `deferTo`，没有补做日期时使用原任务日期；已完成、跳过、已删除任务和已归档或已删除计划不提醒。独立待办使用安排日期，排除已完成和已删除项。逾期查询不限制为近一个月；列表采用服务端分页，默认每页 20 项、最多 50 项，按日期、模式及 ID 稳定排序。

目标路线不设截止日期，单独分页列出未归档路线及完成步数，不计入逾期。查看路线后，仍由原有执行模式及依赖规则决定哪些步骤可以开始。事项链接携带原计划、日期及事项标识；待办进入对应日期的编辑面板，周期任务进入对应计划日程。

## 站内提醒

提醒默认关闭，由本人选择开启；可选择周期任务、今日待办、是否包含逾期及提前天数。开启时至少选择一种事项，随时可以关闭。设置保存到账号下，其他设备联网读取后生效；并发修改必须提交最新版本，不自动覆盖。

站内提示只在应用打开、联网且可见时刷新，间隔五分钟，重新联网、返回应用或保存设置时也刷新。不申请系统通知权限，不发送邮件，不运行系统后台推送，不自动调用 AI。“今天不再提示”仅在当前设备、当前服务器和账号下生效，第二天恢复；它不修改云端提醒开关。离线及强制更新限制期间不显示可能过时的提醒。

## 周复盘

共享入口 `/weekly-review` 可选一周内任意日期，客户端归一到周一；API 只接受周一。以北京时间周一 00:00 至下周一 00:00 为边界。

- 周期计划与今日待办显示本周安排数量及本周完成数量；完成以实际已记录的完成时间计算，不以计划日期代替。已归档但未删除的计划、路线保留在完成统计内。
- 目标路线按步骤完成时间计数，不虚构日期或用时。
- 周期计划投入采用保留的计时流水，包括手工补录和扣减，按流水开始时间归属；手工记录按录入时间归属。正在运行而未结算的时间不计入，跨周计时整条归属开始周，与现有流水口径一致；不声称是按自然周切割后的精确时长。
- 当前遗留为安排日期截至该周日、目前仍未完成的活跃周期任务和待办，包含更早遗留；它是当前状态，不是对历史某日状态的还原。
- 旧待办没有完成时间的不推测、不回填为更新时间，而是显示未能确定完成周次的数量。迁移后新完成时记录时间；取消完成清空该时间，再次完成使用新的完成时间；只改完成事项文字或恢复回收站不会伪造完成日期。

可保存本周收获、遗留与阻塞、下周重点，每项最多 4000 字；历史按周降序分页。文字不会自动生成或修改任务。每个账号每周唯一，首次创建与后续保存均有所有权和版本保护；其他端更新时返回 409 并保留本页输入。读取云端版本前要求确认替换未保存文字，离开页面或刷新时也提示未保存内容。保存期间禁止再编辑，避免响应覆盖新的输入。

## 数据与离线边界

V19 新建 `reminder_preferences`、`weekly_reviews`，为 `todos` 增加可空 `completed_at` 及索引；不修改旧迁移、不重建真实业务表、不删除旧数据。新接口都按当前登录账号限制，并返回 `Cache-Control: no-store`；管理员也不能通过传入其他用户 ID 访问私人复盘。

共享客户端可把已加载页面保存到原有账号和服务器隔离的 IndexedDB 快照，退出清理沿用原机制；这与禁止 HTTP 共享缓存不同。汇总仅使用云端已同步数据，不投影未提交的任务队列，页面明确提示此边界。提醒设置和周复盘保存要求联网，不加入原任务离线队列；未加载的离线内容不伪装成空记录。

## 接口

日期与分页参数详见 [OpenAPI](openapi.yaml)。

- `GET /api/daily/summary`：`date`、`days`；返回周期任务与待办的三个日期分类数量及未归档路线数。
- `GET /api/daily/items`：`date`、`days`、`bucket`、`mode`、`page`、`size`；返回分页事项。
- `GET /api/daily/routes`：`page`、`size`；返回分页路线概况。
- `GET/PUT /api/daily/reminders`：读取或保存本人的提醒设置，未保存时版本为 `null`。
- `GET /api/weekly/summary?start=周一`：本周安排、完成、投入与当前遗留数量。
- `GET/PUT /api/weekly/reviews/{周一}`：读取或保存本周文字，未保存时版本为 `null`。
- `GET /api/weekly/reviews`：分页历史。

写入可用现有 `X-Idempotency-Key` 协议重放完全相同的请求；不能用新键或旧版本绕过 409。

## 集中验收与发布

按本阶段约定先开发全部功能，再集中测试。测试范围为日常体验服务、待办完成时间、共享页面、入口、缓存与合入的教学修复，不重复 AI 付费调用、SMTP 或无关旧业务回归。

源码与安装包版本、签名、升级数据保留、真实数据库备份和云端健康仍为发布门槛。V19 生产迁移前须在独立 MySQL 恢复库验证；新列可空且新表独立，回退应用时不得删除它们或用旧备份覆盖升级后的数据。正式覆盖安装前，用户仍需保存并关闭客户端；Android 系统安装确认由本人完成。
