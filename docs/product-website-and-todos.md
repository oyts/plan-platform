# 产品官网与今日待办

本阶段把计划舱分成公开产品介绍与登录后的业务工作区，并新增不依赖计划或路线的今日待办。代码在本地验收后进入 GitHub；阿里云旧服务保持不变。

## 网页入口

- 未登录访问 `/`：产品首页，介绍周期计划、目标路线与今日待办。
- `/welcome`：始终显示产品首页，登录后也可访问。
- `/login`：账号登录。首页“进入网页版”会进入登录或当前账号工作区。
- 登录后的 `/todos`：今日待办。周期计划和目标路线仍保留各自导航、统计和回收站。

首页示例明确标注“示例”，不展示虚构用户数或运行统计。页脚包含本站ICP备案号及工信部链接，不展示尚未取得的公安备案号。其他部署者应替换本站域名、备案号及客户端信任配置，不能直接沿用。

## 安装包与二维码

首页读取 `/downloads/manifest.json`。当前两个条目均为 `null`，因此不提供正式下载；已有本地验收包不等于正式发布包。

正式发布时，先把经过签名和安装验收的 EXE/APK 上传到同源 `/downloads/`，再发布清单。例如下列结构中的占位值必须替换为实际文件信息：

```json
{
  "schemaVersion": 1,
  "windows": {
    "version": "0.1.4",
    "url": "/downloads/PlanCabin-0.1.4.exe",
    "sha256": "实际文件的64位SHA256十六进制值",
    "bytes": 12345678
  },
  "android": null
}
```

Android 条目结构相同，URL 扩展名为 `.apk`。二维码由浏览器本地生成，不向第三方二维码服务发送 URL 或账号。清单只接受同源 `/downloads/` 下的 HTTPS 地址（本机开发允许 HTTP）、有效版本、SHA-256 和文件大小；无效条目不会变成可点击下载。SHA-256 用于核对文件，不替代操作系统或客户端的签名验证。

首页下载与应用内更新是两个入口。`/client-updates/` 仍须按原生客户端说明发布受信任签名的更新清单，不能用首页下载清单替代它。安装包、签名私钥和真实服务器配置不进入源码仓库。

## 今日待办规则

待办有标题、备注、安排日期、完成状态、删除状态和基础版本。无需选择计划、路线、阶段或标签，也不会影响两种原有模式的完成率。

默认查看今天未完成项；可以查看截至所选日期的近 31 天、已完成项、全部项和回收站。日期使用设备本地日期；每页显示 10 项，支持标题和备注搜索。后端一次最多读取连续 31 天、最多 2000 项，超限明确提示缩小范围，不静默截断。当前是前端展示分页，不是服务端游标分页；大规模历史查询是后续优化项。

删除是软删除，可以恢复。修改、勾选、删除和恢复均提交读取到的 `version`；过期版本返回 409，不能覆盖其他设备的数据。同版本的重复写通过幂等键重放。

离线仅能读取已访问日期范围的账号快照，支持待办新增和编辑入队；未访问的日期范围不会凭空出现缓存。带待同步或冲突标记的条目不能继续叠加编辑，应先去同步中心处理。不同账号和服务器的快照与队列相互隔离。移动日期后的待办不会自动填充到从未加载过的新范围。

## 连接错误的原因与检查

2026-10-12 核对现有云端时，`/api/health` 返回 `plan-console-sync 1.10.1`，`/api/auth/config` 返回 404。HTTPS 首页可达，但旧服务没有新版账号接口。更换证书、清理手机缓存或反复输入同一个旧地址不能解决接口版本不兼容。

新版登录页会区分账号接口不存在、HTTP 访问错误和网络不可达，提供重新检查按钮。正确环境应让 `/api/auth/config` 返回 JSON 账号配置（含布尔值 `registrationEnabled`，新增 `todoEnabled`），并让 `/actuator/health` 返回 Spring Boot 健康状态。

下一次云端切换必须先完成独立 MySQL 数据库与备份恢复验收、初始管理员与邀请注册配置、独立端口上的新版部署、旧版数据导入验收和 Nginx 回滚配置。原云端 43127 端口已经被旧服务使用，不能直接套用新 Compose 文件占用它。新版完成验收后才切换域名；旧版备份脚本不能代替新版 MySQL 备份。

## 验收范围

后端集成测试覆盖待办所有权隔离、版本冲突、软删除恢复、幂等创建和参数校验；前端单元测试覆盖日期、离线投影、模式隔离、清单校验与旧服务诊断。Playwright 覆盖桌面及手机视口的官网、二维码、待办编辑与分页、模式切换、离线重开和同步。

本轮后端 28 项、前端 129 项测试通过，完整浏览器验收 62 项通过、6 项按设计跳过（仅限手机的用例不在桌面项目重复执行），生产构建及 PWA 资源检查通过。

H2 自动测试不等同于 MySQL 8.4 部署验收；浏览器手机视口测试不等同于 APK 真机测试。本阶段没有安装新原生包、修改客户端正式更新源或替换阿里云服务。
