# 0.1.5 发布验收记录

日期：2026-10-13。Web、API、Windows 与 Android 已统一为 0.1.5，Android 构建号 9。云端及 Windows 下载实际发布完成，Android 保持私测。此记录区分本轮证据与仍需补充的场景。

## 本轮修改

注册确认密码、手机待办日期布局、共享成员页手机适配、动态版本发布工具、旧 Windows 下载保留与文档一致性。公开注册及公开 APK 仍关闭。

## 已验证

- 后端 29 项测试通过；Flyway V1—V13，无本轮新迁移。
- 前端单元测试 135 项通过；类型检查、Web 和双端业务资源构建通过。
- 完整 Playwright：74 项通过，6 项按设计跳过；含真实本地注册确认密码和会话刷新、邀请注册零错误请求、窄屏日期布局、离线与冲突。
- 正式 EXE/APK 构建及真实签名验证通过，沿用原签名身份。
- Windows 0.1.4 → 0.1.5 原目录覆盖完成：启动前 370 个原应用数据文件哈希不变，凭据未导出或修改。
- Android 同包覆盖完成：0.1.4/8 → 0.1.5/9。维护者确认三种模式、登录、休息日及队列、关闭重开均正常；这是人工正式包验收，不冒充本轮 Android 自动业务回归。
- PC 正式包自动只读检查：三模式、原计划、同步中心与云端连接正常；关闭重开保留登录。同步中心为 0 项本地操作、0 项冲突，不能据此证明非空队列升级保留。
- 发布与签名工具 15 项测试通过，含不可变旧下载、同版本冲突拒绝、APK 拒绝与备份边界。
- 生产升级前 MySQL 备份已验证；云端部署为 `releases/0.1.5-50aa3a3e5f51`，HTTPS 健康和账号配置确认新版。公开注册、邮件找回仍关闭，邀请开启。
- 正式网站 27 项业务回归全部通过，含桌面及手机视口、三模式、离线重放、409、数据隔离；不冒充 APK 自动回归。
- 正式网站注册 UI 检查 2 项通过：确认密码显示与遮蔽、不一致时零注册 POST、无邀请时注册仍关闭。只用无效合成邀请，不创建生产账号、不消费真实邀请；真实注册提交另由本地 H2 和邀请 UI 测试覆盖。
- Windows 正式 HTTPS 发布检查 5 项通过，本地静态发布检查 4 项通过；两个旧 0.1.4 EXE URL 实际下载哈希仍与原包相同。

官网：[plan.zijun701.cn](https://plan.zijun701.cn/)。Windows 下载清单及可选更新源均为 0.1.5，最低支持版本维持 0.0.0，自动下载默认关闭。Android 清单为空，公开更新与 APK URL 保持 404。

## 发布归档

业务源码已推送 GitHub，提交 `50aa3a3e5f518752dd1b8d1b405e83d77d7b42c4`。验收记录与发布工具随后提交，`v0.1.5` 标签及 Release 对应最终归档提交，附件仅 Windows EXE、签名和校验和，不含 APK。

[GitHub Release v0.1.5](https://github.com/oyts/plan-platform/releases/tag/v0.1.5) 已公开，标签保留在 `5b1c2ed0f61ff448acfb70ef9e7e51342be9da59`，后补发布工具及测试修复不移动标签、不替换安装包。GitHub 把附件名空格规范化为点号，真实 Windows 安装包哈希已核对一致。

一次 CI 的手机路线用例在导航辅助函数中误开“更多”弹窗而超时；同一版本其他运行及正式网站回归通过。已修复测试脚本等待模式和路由完成后再找入口，双视口各重复 5 次共 10 次通过；不改运行时产品代码、不强制点击遮挡元素。修复后的 CI 随提交重新触发，不能把原失败运行写成通过。

Android CI 保留构建与单元测试，停止后续调试 APK 附件上传，防止与受邀私测策略冲突。本次未删除历史 CI 调试产物；它们不是正式签名 APK，不能作为朋友升级包。

## 验收边界与后续补充

- 本轮验证的是正式覆盖安装、官网真实下载签名和原生更新检查；没有再次执行正式 0.1.4 应用内下载安装链路。
- 非空离线队列跨版本保留的本轮专项尚未执行；不能由启动前文件哈希或空队列检查替代证明。此前 0.1.2 → 0.1.3 的人工队列升级证据仍属于旧版本记录。
- Windows 尚无 Authenticode 发布者证书，可能显示未知发布者；Updater 签名不能消除此系统提示。

安装包、受限验收证据与实际账号资料不进入公开仓库。升级复现顺序见 [发布流程](release-process.md)。
