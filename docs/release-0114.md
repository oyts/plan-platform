# 计划舱日常体验阶段

本阶段包含今日与逾期汇总、默认关闭的站内提醒、私有周复盘和教学日期提示修复。2026 年 10 月 18 日正式 Web/API、Windows 官网下载与可选更新源、Android 登录受限更新源均已发布为 `0.1.14`，Android 构建号 `19`。公开注册、官网 APK 和二维码仍关闭。

## 功能范围

共享的“今日与提醒”和“周复盘”入口不改变三种模式的独立工作区。事项可以按模式及日期分类分页，跳转至原业务处理；目标路线不标记逾期。提醒由用户主动开启，可关闭，不发送邮件或系统后台通知。周复盘支持当前云端统计、文字编辑、分页历史及版本冲突保护。

教学修复合并进本阶段：超出 31 天明确显示实际天数及可选结束日期，修改后直接继续，保留输入与教学进度，不单独发布。

完整业务口径、隐私和离线边界见 [日常使用体验](daily-experience.md)。V19 增加独立私有表和可空待办完成时间，不推测旧待办完成日期。
