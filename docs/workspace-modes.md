# 周期计划与目标路线

本阶段将两种使用方式分成独立工作区。周期计划用于在一段时间内安排每日任务；目标路线用于没有固定结束日期、按空闲时间逐步推进的长期目标。界面沿用手机布局阶段的蓝白配色、细分隔线和触控规范，不增加新的设计依赖。

## 模式切换与入口

登录后的顶栏提供“周期计划”和“目标路线”选择器，Web、Windows 和 Android 复用同一套界面。选择模式会切换首页、导航和记录页面，不启动、暂停或完成计时器。

| 工作区 | 首页 | 手机主导航 | 其他业务入口 |
| --- | --- | --- | --- |
| 周期计划 | 今日控制台 | 今日、日程、计划、更多 | 统计、复盘、记录、导出 |
| 目标路线 | 继续路线 | 继续、路线、进展、更多 | 路线记录与恢复 |

账号、服务器设置、同步中心、客户端更新和管理员成员管理为共同入口。同步队列仍按服务器与账号隔离，不因为切换模式而拆成两条队列；强制更新限制仍优先于模式导航。

周期计划的休息日、日期范围、任务、标签、统计和复盘保持原有行为。目标路线首页展示已有路线的完成步骤、下一项可继续的步骤和已记录投入；“路线进展”只汇总路线数据，不混入周期计划，也不计算每日配额、逾期或日历欠账。投入时间是暂停或完成后保存的累计值，不是实时运行计时。

## 位置记忆与账号隔离

两个模式分别保留最近访问位置。路线选择以 `/mainlines?line=路线ID` 表达，切换回来会回到该路线。同步、设置等共同页面不会覆盖任一业务位置。偏好按服务器和账号保存在当前设备，不跨设备同步，也不用于恢复登录凭证。

导航偏好使用独立 IndexedDB 保存，并在进入业务页面前等待事务完成，避免 Android 被终止时丢失尚未落盘的模式切换。旧 localStorage 偏好可继续读取；当设备拒绝本地存储时仍允许导航，但不能保证下次重开记住位置。

退出时清空内存中的当前工作区；另一个账号不会看到前一个账号的路线选择。原账号重新登录可以读取自己的导航偏好。无效或损坏的偏好退回对应首页；已删除的路线选择退回当前账号仍可访问的路线。计划详情被删除后仍由原页面提示不可用，可从计划入口返回列表。

离线时只能查看之前联网加载过、且仍在有效期内的内容。模式切换不扩大缓存范围，也不让计时、完成、删除或回收站恢复变成离线操作。普通计划任务编辑继续复用既有离线队列与冲突处理。

## 数据兼容与开发边界

这次是工作区与展示层改造，不修改数据库、API、旧版迁移格式或离线同步协议。原 `/mainlines` 页面仍有效，内部 `Mainline`、`MainlineItem` 和旧 JSON 字段保留，避免已有路线丢失。周期计划与路线的回收站分别过滤自己的内容，恢复仍走同一套受所有权保护的接口。

目标路线当前仍使用已有顺序解锁规则：前一步未完成，后一步由服务器锁定。自由顺序、可选前置依赖、阶段分组、路线暂停与恢复、步骤编辑面板、长列表折叠或分页、AI 路线导入属于后续开发，不应把本阶段视为这些功能已经完成。

本阶段仅本地开发和独立测试，不部署阿里云、不更改公开更新源、不替换正式 0.1.3 客户端。

## 验收入口

前端单元测试覆盖模式归属、两套位置记忆、服务器与账号隔离、偏好校验及路线进展计算。浏览器验收见 `web/e2e/workspaces.spec.ts`，覆盖两套导航、切换回来、重新登录、接口断连后的缓存读取、统计分离、回收站过滤和旧 URL 兼容。

真实 EXE 和 Android 测试在 `scripts/native-regression.mjs` 中执行，使用独立包、合成账号与内存数据库，包含真实 TCP 断连后的路线重开。运行与隔离说明见 [原生客户端自动化回归](native-regression.md)。实际结果以每次生成的报告为准；浏览器接口拦截测试不能替代真机离线重开结论。

## 本轮结果

2026-10-04 的最终构建通过 104 项前端单元测试与 6 项回归框架测试。完整浏览器回归为 44 项通过、6 项按设计跳过、0 失败；跳过项为桌面项目中重复注册的手机专用测试。

Windows 独立 EXE 与 iQOO V2426A（Android 15）完成 10 项真实原生场景，全部通过。最终记录为 `acceptance-results/native/2026-10-03T16-23-51-062Z-42a33b72/report.json`，目录时间使用 UTC，本地运行日期为 10 月 4 日。

早期真机运行发现 Android 快速终止后的 localStorage 偏好丢失，已经通过事务持久化修复并在最终整轮重测通过；安装超时及修复前失败报告保留，不混入通过数量。正式 Android 安装版本在测试前后均为 0.1.3，未清除原应用数据。

本机报告和合成数据截图保存在 Git 忽略目录：`acceptance-results/native/latest.html`、`web/playwright-report/index.html`、`acceptance-results/workspaces/mobile-route-home.png` 与 `desktop-route-home.png`，不随源码公开发布。没有新增加正式签名更新、云端部署或其他厂商手机兼容性通过结论。
