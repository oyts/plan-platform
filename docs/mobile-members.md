# 成员邀请手机布局验收

成员邀请页已使用与其他页面一致的白底、蓝色操作按钮和底部编辑面板。窄屏与手机横屏显示邀请卡片，长邮箱与创建人标识自动换行，状态和撤销操作可直接查看；桌面继续使用表格。创建邀请与一次性注册链接位于独立面板，关闭后本次链接仍可从当前页面重新查看，刷新页面后不能恢复。

原布局的表格撑大了手机页面，同时拉宽邀请表单。现在列表容器限制宽度，手机端不依赖横向滚动；创建与撤销按钮至少 44 像素高。邀请仍需真实后端鉴权，未更改管理员权限、公开注册或成员数据隔离。

修复已编入新的独立原生回归包及长期签名候选包，后者见 [正式客户端发布](formal-client-release.md)。网页生产资源、正式客户端安装与公众下载各自需要单独发布或验收，不能因为本地浏览器测试通过就认为手机已收到修复。
