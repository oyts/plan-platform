# 系统通知与事项提醒

账号规则和设备级原生提醒已随0.1.18／Android23发布，当前正式三端为0.1.19／Android24。平台投递证据见[提醒续做记录](native-reminders-progress.md)与[0.1.18发布记录](release-0118.md)，不能从当前版本号推导本轮又执行了提醒全量测试。提醒不能代替用户确认，也不自动开始、完成或改写事项。

## 规则与状态

提前提醒、到点开始提醒、每日待办收尾分别设置，默认全部关闭。提前默认5分钟，可选1至120分钟；待办默认22:30，仅当天存在未完成待办时提醒。使用明确时区，支持跨午夜免打扰、隐藏正文和主提醒设备。无开始时间的任务不生成到点提醒，长期目标路线不算作每日欠账。

发出前必须联网读取本人最新状态。完成、跳过、删除、归档、延期和已开始的任务不会作为原时间的未开始任务通知。新增`ever_started`保留暂停后清空开始时间仍已开始的证据；V26只回填数据库中仍可证明的开始记录，不虚构旧历史。

账号规则随服务器同步，设备开关不跨设备自动开启。每台设备须本人选择，最多8个有效授权，30天后须重新开启。设置保存使用版本校验，冲突返回409，不覆盖尚未保存的选择。

## 安全与投递

后台只持有专用、可撤销的提醒设备授权，不复制登录刷新凭据。服务器只保存授权的SHA256；原始值只在注册响应及原生Keyring或Android Keystore加密存储中出现，不写入普通幂等响应缓存。设备授权不能登录、读取任意业务接口或调用AI。账号停用、会话代次或密码变化、退出全部设备会使后台授权失效。

每次系统唤醒执行一次有超时和响应大小限制的请求，读取最新状态后领取通知。通知按设备和事件防重；领取响应丢失时不重发，宁可漏发而不重复打扰。过期超过5分钟及免打扰期间的事件跳过，不积压补发。当前有效通知窗口内短期复核，其他时间最多15分钟重新查询；这不是远程即时推送。

本机在线修改相关事项后撤回本机通知并安排重新核对；其他设备的修改在下一次核对后才生效。出现本机未同步操作前关闭本机提醒，防止以旧云端状态发出通知；不删除离线队列，完成同步后由用户重新开启。退出账号、换服务器或换账号清理本机授权和本应用的系统调度。

## 平台边界

Windows使用安装身份和当前用户的单次计划任务，`InteractiveToken`、`LeastPrivilege`，不要求管理员、不唤醒关机电脑、不在重新登录后补发旧事件。点击通知打开同服务器网页，浏览器可能需要另行登录。系统通知状态读取失败显示未知，不显示“已经授权”；最终是否投递由Windows决定。

Android使用AlarmManager及本应用Receiver，不使用网页定时器投递。通知权限和精确提醒授权由本人处理；未授予精确权限时使用可能延迟的系统调度。重启、升级和时间变化后重新核对；系统强停、厂商冻结、关机或省电策略仍可阻止唤醒，不能保证准点送达。不会自动关闭系统安全保护或代替用户修改后台权限。

网页版提供规则配置并保留原有前台站内提醒，不承诺关闭浏览器后投递。系统通知是设备自愿开启的新增能力，不影响手动业务、AI草稿或原有离线功能。

## 数据与兼容

V26新增三张提醒表及开始证据。开始证据自个人备份schemaVersion 2纳入；当前格式4兼容1—3及原有校验和、防重语义。备份不含设备授权、系统权限或后台调度，不恢复运行中的计时。迁移、恢复和旧版本兼容已按对应发布完成独立演练；未来改动仍需当时的验证，不能只复用本页历史结论。

## 验收入口

- 后端定向：`NativeReminderIntegrationTest`、`ReminderPollLimiterTest`及直接受影响的`PersonalDataIntegrationTest`、`DailyExperienceIntegrationTest`。
- 前端定向：提醒规则、原生账号切换、离线队列及API成功变更后的刷新事件。
- 浏览器：`web/playwright.reminders.config.ts`。用例使用模拟API，不代表真实后端或原生权限验收。
- Windows：`scripts/desktop.ps1 -Action notification-probe`生成独立安装包；`--reminder-probe`只在debug regression身份存在，验证一次系统任务唤醒和合成通知，不访问真实账号。完成后用同包`--reminder-clear`清理自有测试任务。
- Android：`scripts/android-reminders-acceptance.mjs`校验已安装独立APK字节，使用隔离H2及合成账号。系统权限由用户处理，不操作正式应用。`reminder_test_active`只在独立debug包返回本应用提醒标识，不读取其他应用通知。

当前结果及剩余门槛见[提醒阶段续做记录](native-reminders-progress.md)。
