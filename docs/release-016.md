# 0.1.6 受限 Android 更新接入记录

日期：2026-10-13。此版本是 0.1.7 完整实机升级验收的接入起点，不是最终三端发布完成声明。

新增登录后的 Android 更新清单与 APK 接口、同域凭据校验、账号/服务器切换隔离、私有发布与回滚工具。自动下载仍默认关闭，安装仍由用户与系统确认。注册、官网 APK、Android 二维码继续关闭；签名身份和应用包名不变。本次无数据库迁移，仍为 Flyway V1—V13。

已通过：后端 34 项、前端 142 项、Android Java 编译及单元测试、正式双端候选包签名核验。完整 Playwright 74 项通过，6 项按设计跳过。发布/签名工具 19 项通过，含不可变旧下载保留。临时目录沙箱权限导致的一次测试失败已在本机用户环境复跑；另修复关闭可选更新服务时配置缺省造成的初始化失败，最终后端全量通过。

首个候选包目录：`production-artifacts/client-release/0.1.6/20261013T054417Z-55095065`。构建号 10，APK SHA-256 为 `03e4a5427086d684cc6d38ce63a219caa93cac65b026052af2f9983e8a9428d3`。该包签名和接口下载核验通过，但最终编译常量检查发现签名构建脚本覆盖了新更新源，仍绑定旧静态 URL。未安装到手机，已撤回远端更新配置，保留候选与服务器文件，不复用构建号。修复签名脚本并增加正式构建保护后，使用构建号 11 重新准备 0.1.6；0.1.7 将使用构建号 12。

待完成：0.1.6 → 0.1.7 应用内系统安装、跨版本数据与会话保留，以及最终 Windows/官网/GitHub 0.1.7 发布。每项按实测追加，不以模拟测试替代真机结果。
