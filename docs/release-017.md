# 0.1.7 受邀应用内更新验收

状态：开发与候选准备中，尚未完成最终发布。Web/API/Windows 目标版本 0.1.7，Android 构建号 12。

此版本用于从已验收的 Android 0.1.6 / 11 执行真正的应用内下载、完整性及签名校验、用户与系统确认安装。沿用原应用身份和证书，不手动推送目标 APK，不卸载或清数据。官网仅发布 Windows，Android 受登录后的 API 保护，公开注册仍关闭。

0.1.6 接入、回归证据及撤回首个错误地址候选的说明见 [接入记录](release-016.md)。最终结果、安装包哈希、部署路径、实机数据保留、GitHub 提交与未完成边界将在实际验收后追加。
