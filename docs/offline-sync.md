# 离线队列与幂等提交

## 离线工作区（2026-10-03）

已加载的计划列表、计划任务与标签、今日控制台、日程查询和统计快照会写入独立的 `plan-platform-cache` IndexedDB。模板、里程碑、循环规则和主线列表也可读取已缓存的查询结果。缓存按服务器、账号、API 路径和查询参数隔离；未访问的周、分页或日期范围不会被伪装成空列表。导出文件、账号资料接口、会话、成员管理和未知接口不缓存。

只有最近一次成功联网验证后的 24 小时内，才能用本地身份离线重开。这个身份只用于读取本机数据和保存本地操作，不是服务端登录令牌，也不授予服务器权限。离线读取不延长有效期。响应最多保存 100 个查询结果、最长 7 天；过期身份不能借此继续读取。

计划与任务的普通编辑通过队列投影立即显示，并标为“本地修改 · 待同步”，不会修改缓存里的服务器基础版本。发生冲突时显示服务器快照与待处理标记，不覆盖另一端。新建计划、任务和标签以本地草稿显示；新计划需同步成功后才能添加关联任务，新标签需同步后才能用于任务。已有本地操作的同一记录需先同步或放弃旧操作再编辑，避免重复旧版本提交。

每周休息日属于计划配置，可在创建计划时选择，也可从“编辑计划设置”调整。默认没有固定休息日，不再把周六、周日直接标为休息日。离线修改 `restDays` 后，已缓存的日程会使用本地待同步配置显示标签；服务器基础版本仍保留供冲突检查。休息日不阻止查询、缓存、安排任务或补做，也不自动移动或删除任务。未缓存的日期范围仍需先联网加载，修改休息日不会凭空生成缺失的查询缓存。

顶部连接状态根据服务器是否可达判断，不只依赖 Wi-Fi 图标。USB 转发断开、但手机仍有 Wi-Fi/移动网络时，也会使用本地缓存。点击“恢复连接”重新验证账号；点击“同步等待项”也会先验证身份，再按原顺序提交，不自动覆盖或自动清空队列。统计与执行进度仍是历史快照，不承诺离线重新计算。

退出登录会原子地清除当前服务器的页面缓存并记录退出意图，防止离线时未撤销的 HttpOnly Cookie 在下次联网重开时自动恢复账号。未同步队列另行保留，只有原服务器和原账号重新登录后才能查看与提交。切换服务器清除对应离线身份；请求发出后退出或切换账号，迟到响应不能重新写回缓存。HTTP 401/403/404 不以离线快照掩盖；401 刷新验证失败会清除本地身份。

页面缓存和操作队列不是加密存储，不保存 Access Token、Refresh Token 或密码。仅在自己可信的设备使用；它们不能替代服务器备份。原生登录凭据仍使用 Windows 凭据管理器 / Android Keystore，与页面缓存分开。

## 支持范围

Vue 客户端会把计划、任务、标签、里程碑、模板和主线的普通新增、编辑操作暂存在 IndexedDB。计时、完成、手动补录、延期、循环任务等时间敏感操作必须在线。

删除操作也必须在线：现有删除接口没有携带实体基础版本，将它离线排队可能误删其他设备刚更新的数据。后续只有在删除协议加入版本前置条件后，才应开放离线删除。

离线请求只保存用户标识、方法、相对 API 地址、查询参数、JSON 请求体、创建时间、顺序号、尝试次数、状态和幂等键。认证头、Cookie 和用户密码不会写入 IndexedDB。Web 按用户隔离；原生客户端按服务器根地址和用户共同隔离，切换身份不会读取或重放其他身份的操作。

IndexedDB v3 在同一事务中分配递增顺序号并写入记录，保证同一毫秒的并发入队仍按先后处理。v2 升级保留原记录，旧记录先按时间排序，同一时间按操作键稳定排序；旧版本未记录的真实先后顺序无法追溯。重试使用原键并保留原顺序。

## 提交流程

1. 客户端为支持的写操作生成 `X-Idempotency-Key`。
2. 在线时直接提交；网络不可达时用该键写入本地队列。
3. 同步中心使用原键重放请求。
4. 服务端在执行写操作前预留键，完成后保存状态码、Content-Type 和响应体 24 小时。
5. 重复请求的用户、键、方法、路径、查询参数和请求体完全一致时，服务端返回已保存响应，并附带 `X-Idempotent-Replay: true`。
6. 相同键对应不同请求内容、操作仍在处理中或实体版本过期时返回 `409 Conflict`。

## 冲突处理

同步中心不会通过“最后写入者获胜”静默覆盖数据。出现冲突时：

1. 本地操作标记为“需要处理”，保留请求内容和服务端错误。
2. 用户进入对应业务页读取服务器最新版本。
3. 核对最新数据后，先在同步中心明确放弃旧操作，再按需要重新编辑并生成新的操作键；未处理旧操作时，不继续为同一记录追加旧版本请求。

放弃操作只删除当前浏览器中的队列记录，不修改服务器数据。

网络失败、鉴权失败和 409 都会暂停后续提交，即使 `navigator.onLine` 仍为真，也不会跳过失败项。界面只允许重试队首；冲突项须查看最新数据并明确决定是否放弃。支持 Web Locks 的浏览器会阻止两个窗口同时重放同一身份的队列；不支持时仅有窗口内互斥，服务端幂等仍负责防重复。

## 运维边界

- Flyway `V10` 创建 `idempotency_records`；过期记录会在后续幂等写入时清理。
- 当前队列属于单个浏览器配置文件，不在不同设备之间复制。
- Service Worker 仍不缓存 `/api/**`，避免把私有响应当成离线数据源。
- 真正的字段级三方合并需要保存共同基础快照，本阶段不承诺自动合并语义。
- 服务端幂等记录保留 24 小时，不承诺无限期去重；长期离线且曾发生“服务器成功、响应丢失”的操作应先核对服务器数据再重试。

自动与原生验收见 [跨客户端验收](cross-client-acceptance.md)。
