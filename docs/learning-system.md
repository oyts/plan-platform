# 使用教学与独立练习区

使用教学帮助第一次接触计划舱的成员区分三种工作模式，并亲手完成一个小案例。原四节课程已随 0.1.8 发布到 Web、Windows 和 Android；三端共用 Vue 业务源码。0.1.12 已发布第五节 AI 规划教学，Windows 与 Android 真机的四步交互、保存重开及节奏示例已通过定向验收，见 [0.1.12 发布记录](release-0112.md)。历史记录见 [0.1.8](release-018.md)。

## 教学入口

0.1.19／Android24已发布第六节“整套模板”：选择本人结构类型、核对保存范围、重新命名和选择周期、确认副本独立。使用合成内容，不调用AI、不生成真实模板，不改变原五节进度。独立Android四步练习及重开、Windows练习入口及正式双端入口已分别验收，见[0.1.19记录](release-0119.md)，不把入口检查称为全部原生步骤重测。

首次进入周期计划、目标路线、今日待办、同步或 AI 规划页面时，页面上方提供“开始教学”和“稍后再看”，不弹出强制对话框。各节提示独立：跳过周期计划教学不会关闭待办教学。

桌面主导航的“使用教学”、手机“更多”中的同名入口，都可打开 `/learn`。完成后仍可回顾，并通过“重新练习”只重置这一节的教学内容。教学结束页给出真实页面的操作路径，可跳转到对应功能。

| 课程 | 小案例 | 练习内容 |
| --- | --- | --- |
| 周期计划 | 七天阅读练习 | 设置周期、选择休息日、安排任务、查看完成进度 |
| 目标路线 | 从零学习吉他 | 写下目标、划分阶段、指定前置步骤、解锁下一步 |
| 今日待办 | 寄出一份资料 | 记录事项、补充备注、标记完成、重新安排 |
| 离线与同步 | 两台设备修改同一任务 | 预先缓存、本地保存、比较冲突、选择保留版本 |
| AI 规划 | 两周英语复习 | 说明目标与选模式、预览手改、勾选并确认生成、对照并确认放慢 |
| 整套模板 | 复用一套阅读或路线方法 | 核对保存范围、预览模板、确认建立独立副本、验证来源互不影响 |

每节四步。必须完成当前操作，才可继续；也可返回上一步。练习中的休息日采用真实业务的星期编号（星期一为 1，星期日为 7），不会默认把周末设为休息日。阅读案例要求选择一个计划日来安排任务，这只是练习限制；真实计划允许休息日补做。

AI 教学的回复和计划为明确标注的本地示例，不连接 DeepSeek、不扣每日额度。必须亲手改动示例任务标题，再练习勾选确认和点击生成；最后预览“未开始事项 20 → 10 分钟”并确认应用，已完成记录保持不变。真实 AI 页面仍需联网、满足额度并自行同意第三方处理；教学不代替这项同意，也不自动发送请求。旧版 v1 教学存储会补入一节未完成的 AI 课程，原四节进度不重置。

## 数据与保存边界

练习区明确标为教学模拟，不调用业务写入接口，不创建真实计划、路线或待办，不进入真实离线队列。同步课的网络切换、冲突和版本选择都是模拟，不会操作真实待处理项。

教学进度、跳过状态和练习输入写入设备的 IndexedDB，按服务器和账号隔离，不跨设备同步。下一步、完成教学和“保存练习”都等待事务提交；保存期间阻止页面内部导航。填写到一半时，离开前点击“保存练习”，等保存成功再关闭或刷新。系统强制终止应用时，尚未提交的输入不保证保留。

退出账号或切换服务器会清空内存中的教学上下文。重新登录原账号可恢复该设备已保存的教学进度。卸载应用、清除站点数据，或设备拒绝存储时，教学进度可能重置；存储失败会明确提示，不影响业务功能。

教学沿用既有离线应用壳。已加载的教学页面可在 API 断网时继续练习；首次安装或从未缓存过的 Web 应用壳仍需要联网。教学不绕过登录、邀请注册或强制客户端更新限制。

## 日期校验提示优化

周期计划教学的日期校验与下一步提示优化已于 2026 年 10 月 18 日合入 `0.1.14` 并发布到 Web、Windows 和 Android。功能与验收范围见 [0.1.14 发布记录](release-0114.md)；尚未升级的 `0.1.13` 安装包仍使用原提示。

练习周期填写 `2026-10-18` 至 `2026-11-18`，包含首尾共 32 天，超过教学的 31 天限制。原版只显示通用提示并禁用“下一步”；新版在日期字段与按钮附近分别说明具体原因，显示实际天数及最晚可选结束日期 `2026-11-17`。缺少名称、缺少日期、无效日期和结束早于开始分别提示，修正后立即更新按钮状态。提示通过字段描述、无效状态和礼貌播报提供给辅助阅读工具。

“保存练习”仍可保留尚未修正的输入，但不会解除校验限制；有效输入可以直接点“下一步”，无需先保存。日期不会被静默修改，教学存储格式不变，不清理账号、其他课程进度或离线队列。31 天仅为教学练习限制，不限制正式周期计划。界面沿用前端设计技能确定的现有白底蓝色细线网格，不重做布局。

定向验证只覆盖教学模型与受影响页面，不调用收费 AI、发送邮件或修改真实业务。12 项单元测试通过，包括 31/32 天边界、当天、闰年、跨年、缺失与反向日期、旧输入及其他课程进度保留；桌面和手机视口共 12 项浏览器测试通过，验证保存重开、修正后直接继续、其他教学流程与 320 像素布局，并检查操作按钮未被固定导航遮挡。证据位于本机忽略目录 `acceptance-results/learning-dates-20261018-verified/`。Web、Windows 页面资源及 Android 页面资源均通过构建；资源构建和浏览器手机视口不等于正式 EXE/APK 真机验收。

后续发布需统一递增版本与 Android 构建号，使用原身份签名，在保留账号和数据的覆盖升级后，只补验受影响教学步骤，再更新正式下载及受限 Android 更新源。当前未改动这些线上通道。

复验命令（在 `web` 目录，按现有本机验收环境配置 Java 21、Node 和 Playwright 浏览器）：

```powershell
npm run test -- src/learningModel.test.ts
npm run build
npm run build:desktop-web
npm run build:android-web
npx playwright test e2e/learning-dates.spec.ts e2e/learning.spec.ts --reporter=list
```

## 本地验证

在 `web` 目录执行：

```powershell
npm run test
npm run build
npm run build:desktop-web
npm run build:android-web
npx playwright test
```

浏览器测试使用独立的本机 H2 验收服务，不能连接生产数据库。需先按现有回归流程准备 `backend/target-acceptance/plan-platform-api.jar`，并设置 Java 21 和 Playwright 浏览器路径。

新增测试覆盖首次提示与跳过、四节交互案例、操作前置条件、保存刷新、API 离线、账号和服务器隔离、损坏记录、存储失败以及 320 像素布局。还会监视业务写入请求，并核对测试账号的业务列表始终为空。
