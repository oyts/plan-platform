# 计划舱演示路线与项目讲解

计划舱是面向小范围受邀用户的多端个人规划平台。求职展示应以可解释的所有权、事务、离线与 AI 确认流程为重点，不把浏览器模拟或构建成功说成三端真机验收，不宣称公开 APP 上架、高并发商用或微信小程序已经上线。

截至2026年10月22日，Web/API、Windows及登录受限Android均已交付0.1.19／Android24；当前资料以[交付索引](stable-handoff.md)和[发布记录](release-0119.md)为准。GitHub开源与Windows公开下载不表示Android已经公开上架；公众注册仍关闭。

## 三到五分钟演示

打开 `/help/demo`（原生为 `#/help/demo`），无需登录。所有内容明确为合成案例，只在页面内变化，不写账号、不调用DeepSeek、不扣次数；离开后不保留演示勾选。它适合投屏介绍，不是服务器一致性测试。

1. **0:00—0:45 选择模式。** 展示“两周阅读”：固定周期和星期日休息。切到“从零认识吉他”：阶段推进，没有截止日期。切到“今天的小事”：临时事项无需建长期规划。说明为何不是一个列表加三个名称。
2. **0:45—1:30 完成与保留。** 在演示勾选一项，再切换模式，说明三个独立工作区。强调真实业务的进度、计时和完成记录由服务器维护。
3. **1:30—2:30 AI 的边界。** 点“查看本地示例建议”，说明这是固定示例。展示保留完成记录、只调整未来阅读量的差异，点“仅应用到演示”。实际 AI 必须经用户同意发送必要内容、预览与确认，不能直接执行任意模型输出。
4. **2:30—3:30 讲一个离线冲突案例。** 设备 A 和 B 读取版本 4；A 保存成 5，B 提交版本 4 得到 409。B 的本机内容保留，人工选择字段后基于版本 5 生成新操作，不能静默最后写入覆盖。帮助页提供边界说明，真实队列演示只用独立合成账号。
5. **3:30—4:30 展示可复用方法与工程门槛。** 在已登录合成账号的隔离测试包中打开“使用教学 → 整套模板”，演示先预览、再确认建立独立副本，说明不复制执行历史；该练习不写真实业务。没有合成账号时只展示无需登录的帮助与演示，不借用管理员账号。打开版本检查，说明页面、安装版本和服务器API是三个不同状态，即使当前都为0.1.19也需分别核对。MySQL恢复及性能只引用实际记录。

需要真实业务写入时，使用新的隔离数据库与合成账号，保留操作和失败证据。不要在面试屏幕展示真实邮箱、计划、邀请链接、API Key、备份正文或聊天内容。不能为了演示开启公众注册、给真实朋友发邮件或自动产生付费 AI 请求。

## 可用于简历的项目描述

> 计划舱：基于 Java 21、Spring Boot、MySQL 8.4 与 Vue 3 的多用户规划平台，共享页面交付 Web/PWA、Tauri Windows 和 Capacitor Android。实现周期计划、长期路线与独立待办，以及基于用户确认的第三方 AI 规划。围绕跨设备一致性设计所有权校验、乐观锁 409、用户范围幂等重放、离线 FIFO 队列与冲突停靠；使用 Flyway、隔离恢复校验及同身份签名升级维护发布安全。

## 面试时应能解释的五个问题

- **UUID 为什么不能防越权？** ID 难猜不代表授权，查询还必须按本人归属过滤，子记录经父计划／路线验证；管理员也不能直接读私人内容。
- **409 与幂等有什么区别？** 409 保护旧版本写入；幂等解决同一操作重发。相同键不同指纹仍拒绝，不能靠换键覆盖冲突。
- **恢复为什么导入为新记录？** 避免覆盖在用内容；ID 和依赖必须完整重映射，失败整批回滚，运行中计时不能复活。
- **AI 超时为何不直接退款重试？** 上游可能已成功处理，结果未知时重试会重复付费；持久任务和明确状态比“任何错误都重试”更安全。
- **为什么治理会限制回退？** 旧二进制不检查会话代次，回退可能复活已撤销令牌。回退不能只看健康接口，还要保持安全语义。
