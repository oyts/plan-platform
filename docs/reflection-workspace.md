# 日周复盘与AI节奏分析

本轮候选把三种模式的事实汇总、个人复盘和只读AI分析放在“更多 → 日周复盘”。正式站仍为0.1.17，尚未发布本功能；具体门槛见[续做记录](reflection-progress.md)。界面沿用白底、蓝色和细线网格，三模式事实分栏，自述与分析分开，手机顺序排列。

## 事实和自述

周期计划与待办分别列本期安排、当前状态和本期实际完成。目标路线只统计实际完成步骤，不设置每日欠账。安排日期与实际完成日期不是同一分母，不能直接相除当作完成率。旧任务缺少完成时间时标为未知，不推测日期。

日期范围按北京时间计算。投入仅统计已结算周期计划流水，按开始时间归属；不按分钟拆分跨日流水，不推测路线、待办或尚未结算计时。页面标明汇总时间，历史状态可能随后续改动变化，并非冻结快照。

用户可保存收获、阻塞、下一步以及可选精力和负担自述；自述不是健康判断。原周期计划日复盘入口和文字保留。保存使用版本校验，冲突保留输入，读取云端并比较后只更新版本号，再由用户决定是否保存，不自动合并。

本机草稿按服务器、账号和日期隔离，可保存后关闭重开，不进入同步队列。离线仅有已读取事实快照和本机草稿；云端保存、AI和未缓存清单需要联网。离线身份时限仍为24小时。

## 引导与系统提醒

当天有适用周期任务或待办，且首次全部完成时显示一次非阻断引导；空日不视为全部完成，任务重开不会再次提示。保存为已完成复盘后抑制当期提醒。

日复盘预设22:30，周复盘预设星期日22:30，定时开关默认关闭，时间使用北京时间。账号规则与设备系统授权分开。待办收尾、日复盘、周复盘在同一时刻合并成一条通知，并使用稳定标识防重；各自开关不互相打开。Web不承诺关闭浏览器后投递，Android厂商后台冻结仍待实机补验。

## AI只分析不直接改动

先预览选定日期的汇总，可选择包含已保存的自述，另可选择一份本人的周期计划、目标路线或待办必要结构。每次重新选择会取消原同意，不能扫描全部私人计划。预览与建立分析会话不调用上游；明确发送才沿用每日额度计次。

复盘会话只能讨论，后端拒绝从该会话保存规划草稿、切换模式或应用业务。日分析不提供批量节奏调整入口。周复盘标记完成后，用户可另外进入所选对象的既有AI调整流程，重新同意读取、逐项比较，并通过所有权、版本409、原子提交和历史保护；不删除后重建。

主动趋势入口采用维护者确认的保守规则：连续两周完整、已完成的周复盘，两周均有实际事项；讨论、拒绝、稍后再看都冷却14天。不会自动建议加量，加量讨论还需保存明确意愿，并在对话中主动表达有余力。最近调整仅回顾仍在会话保留期内的应用记录，不保证长期历史或效果。

会话继续复用20份、30天边界。讨论文字可单独保存到本机；请求编号与版本在发送前持久保存，网络结果不确定时不更换编号或自动付费重试。供应商不可用不影响手动复盘，未发送文字不会被后台重放。

## 数据与接口

V27新增日复盘、复盘设置、一次引导和节奏冷却记录，扩展周自述及AI只读快照。私有备份格式3包含日周复盘，兼容1、2；恢复为只读新副本，不覆盖当前复盘。CSV可分别导出日、周文字。AI原文、通知授权和本机草稿不进入业务备份。

- `GET /api/reflection/facts`、`GET /items`：按DAY或WEEK及日期范围读取本人事实、分页清单。
- `GET/PUT /api/reflection/days/{date}`、`GET/PUT /preferences`：版本校验保存。
- `POST /api/reflection/guides/claim`：本人一次性引导。
- `GET /api/reflection/trend`、`POST /trend/{start}/decision`：门槛和冷却。
- `GET /api/reflection/targets`：本人单份规划选择列表。
- `POST /api/reflection/analysis-preview`、`POST /analyses`、`GET /analyses`：同意快照、建立会话和历史；付费发送仍用既有AI jobs协议。

所有接口要求登录并响应no-store，不加入离线自动重放。一般AI列表不混入复盘分析会话，避免旧规划按钮误用。
