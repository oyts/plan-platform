## 指标字典

- 注册：users.created_at的UTC时间转换到Asia/Shanghai日期，昨日／7日／30日／自选最近90日；停用单列。不是邀请发送、登录或活跃人数。
- 官网PV：仅主动勾选参与者的介绍页有效事件。不等于所有HTTP请求。拒绝或服务异常不阻断使用。
- 官网UV：本机每天新随机标识；数据库只存每日盐哈希。跨日只能求“日去重访客合计”，无法表示唯一人数。清缓存／换设备可重复，同设备多人可合并；浏览器无法保存时只计PV。
- 分析采集：固定WELCOME枚举；无Cookie／Authorization；同源Origin；1024字节上限；5分钟签名票据；单进程票据和事件各240次／分钟；每日20000PV、10000估算访客。无IP、指纹、跨站追踪。不能保证识别全部机器人或恶意伪造访问，容量上限不影响业务。
- 短期去重48小时到期，正常运行时每分钟清理；停机后下一轮清理，不承诺停止运行的数据库仍能即时删除。日聚合90天、过期日盐清除。备份本身按既有加密／保留制度管理，不声称数据库清理能擦除旧备份。
- AI：保留现有请求状态、失败／未知、每日Token口径。新增上游尝试与修复次数、已知Token尝试数、首轮开始减作业创建时间的平均等待（秒精度乘1000，排队和调度合计，不是精确队列延迟）；未知为空，尝试Token不与父请求总数再相加。现有原文不进入统计查询。
- 运行：只读专用五列日志（时间、枚举类别、状态、耗时、爬虫布尔值），不读取已有原始访问日志。HTML GET、API、全部请求分别统计，耗时是Nginx均值而非P95。爬虫只是有限UA规则匹配布尔值，扫描只是路径类别，不是攻击或攻击者人数。
- 资源：主机CPU、主机已用／总内存、固定本机后端容器的就绪状态（Docker exec，3秒超时，不放开公网actuator）；非容器专属用量、非公网可达性。磁盘／OSS／备份／恢复继续来自原运维模块，不重复采集。

## 预算、缺失和告警

采集每分钟，单轮最多1MiB／20000行／解析2秒，就绪请求另有3秒超时；最多61个分钟桶和61个资源样本，输出≤64KiB，游标≤128KiB。读取积压明确不完整；轮转／截断或无效行后整小时标未知，不通过漏读宣称故障恢复。原始专用日志按4MiB轮转2份（需每分钟检查；不是硬性磁盘配额），解析不扫描其他历史文件。真实ECS耗时、CPU和内存开销尚待独立合成演练，不能由本机测试替代。

180秒过期／未来时间／格式错／符号链接拒绝，页面显示未知。完整连续窗口：5xx至少20请求且≥10%连续2分钟；登录失败≥10、429≥20、扫描≥20各连续2分钟；请求≥100且≥前5分钟中位数5倍连续2分钟。CPU≥85%连续3次、内存≥90%连续3次；恢复分别≤75%／≤80%连续3次。就绪连续2次失败，恢复连续2次通过。无充分样本或停用采集都不自动恢复原事件，不自动封禁。公开分析存储／事务异常返回空正文503及no-store，不经受保护的错误跳转变成401，不泄漏SQL；前端不自动重试。

新告警复用持久事件和邮件表：同类30分钟冷却；批量摘要不含原始URL/IP/UA；SMTP结果未知不自动重发。`TELEMETRY_MAIL_ALERTS_ENABLED=false`为默认值且不替代原邮件总开关。关掉新开关会作废未发的新类待发事件，不阻断原备份告警。真实收件人和启用须另行确认，本轮不发送真实邮件。

## 正式部署门槛（尚未执行，独立演练已通过）

1. 本地生成`node scripts/prepare-runtime-metrics.mjs`，核对候选Nginx／Compose／采集锁／logrotate模板。输出不自动安装、重启或发信。
2. 获本阶段云端独立演练授权后：V33快照到独立V34库、所有旧业务表校验、聚合并发／时区／过期／回放、整库恢复、旧镜像兼容与回退守卫。Nginx配置必须在真实Linux镜像语法检查，合成日志测量实际资源预算；不得读生产原始日志。
3. 候选须同时保留现有AI／SMTP／operations只读挂载、受限Android与Windows下载配置。模板`nginx.conf`尚未替换`client-public/nginx.conf`；不能只安装Compose就声称采集已运行。先备份实际配置，核对当前容器名称、组ID及目录权限，再启用同源`PUBLIC_URL`和只读运行文件。
4. `production-compose.sh`只在受控根目录存在`production-telemetry.yml`时加入该覆盖；未来静态客户端下载重建需显式`--with-runtime-metrics`，防止日志配置丢失。正式安装前须补自动识别／拒绝错误覆盖的验证，不得只依赖手工记忆。
5. Web和独立PC通过后再通知Android真机；均非正式升级验收。签名候选、新版本号、生产备份恢复、正式双端保留升级及可选源发布须另获确认。不能用0.1.23版本号发布不同正式二进制。

2026-10-26独立演练：58张原表原字段保护、V33旧镜像读取、PV／UV并发去重、503原子回滚、真实48小时到期清理、V34完整62表恢复、回退能力守卫、Linux Nginx语法均通过。最终采集器合成21000行、首轮20000行约0.1189秒墙钟／0.1172秒进程CPU、峰值RSS19156KiB；前一项是墙钟耗时，不是主机CPU利用率。独立480MiB／0.6CPU容器、4个合成账号，小样本预热后5次管理接口中位数约95／86／30ms，不能外推并发容量。Linux真实合成文件轮转通过；测试中postrotate替换为true，没有给生产容器发信号。轮转账号组已核对为oyts，使用create0640 oyts oyts／su oyts oyts；后台只读元数据仍通过原operations组101挂载，二者不混用。
