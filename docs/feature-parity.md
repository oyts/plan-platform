# 三端功能与旧版业务对等清单

截至2026年10月23日，正式Web/API、Windows及Android均为0.1.20／Android25，含历史回收站补迁、双邮箱变更及Windows另存为。本清单以 `summer-plan-web` 的日常业务为参照；具体平台证据和边界见[0.1.20发布记录](release-0120.md)，不能从共享源码推导所有原生行为都已验收。旧服务及备份继续保留。

## 已完成：计划执行层与长期计划工作台

| 旧版能力 | 新版实现 | 验收入口 |
| --- | --- | --- |
| 计划、任务、标签的增删改查 | 服务端所有权校验和乐观锁；计划详情页提供标签和任务的新增、编辑、删除 | `计划` |
| 周计划和长计划浏览 | `GET /plans/{id}/tasks/page` 按日期范围分页；页面使用七日日期轨道 | `日程` |
| 休息日补做 | `POST /tasks/{id}/defer`；休息日由创建计划时选择，后续可编辑，不默认将周六、周日全部设为休息日 | `日程` |
| 任务状态、验收、计时、手动补时 | 状态/验收面板、开始暂停、补录实际分钟；全部写入用户私有数据 | `日程` |
| 日计划与实际的分页统计 | `GET /plans/{id}/stats/daily`；按日期服务端分页 | `统计` |
| 标签投入统计 | 按计划日期范围汇总标签、完成数、计划分钟和实际秒数 | `统计` |
| 固定 G1—G5 闸门 | 每个计划可自由新增、调整日期、记录验收证据的里程碑 | `计划 → 阶段与模板` |
| 任务模板 | 用户私有模板的增删改查；模板删除不会影响已生成任务 | `计划 → 阶段与模板` |
| 重复任务 | 每天、工作日、每周同一天，服务端生成独立可编辑的任务 | `计划 → 阶段与模板` |

| 目标路线回收站 | 路线及步骤软删除、恢复；路线阶段和依赖关系独立于周期计划 | `目标路线` |
| 重复任务批次 | 查看已生成实例的批次并停止指定日期起的未完成实例，保留历史 | `计划 → 阶段与模板` |
| 导出中心 | 集中导出计划任务、统计、复盘和计时记录 | `导出` |

## 已收口的对等项

**旧版回收站迁移**已在0.1.20交付：新导入转换四类快照，旧批次需先预检再确认补迁；永久删除标记只抑制陈旧副本，不删除当前编辑或伪造无正文的恢复记录。
重复任务批量调整与完整路线／待办导出已随前轮实现，不再列为未开发项。未来未开始实例的日期、时长与标签调整须预览确认，已执行历史受保护；路线、待办及日周复盘CSV从个人数据中心导出。

## 数据边界

- Web短期访问令牌位于内存，刷新会话使用HttpOnly Cookie；原生刷新会话由平台安全存储保护。API按本人归属隔离业务，本机私有快照、草稿和队列另按账号与服务器隔离，不等于“设备完全不保存业务数据”。
- 所有分页接口采用零基页码 `page`，页容量 `size` 上限为 100。
- 延期任务保留原计划日期，同时以 `deferTo` 作为补做日；同一任务在日程轨道上只出现一次。
