# 旧版业务功能对等清单

本清单以 `summer-plan-web` 的日常业务为参照，约束 Spring Boot + Vue3 重构项目的迁移顺序。旧版仍是当前线上版本；本项目在验收和迁移完成前不替换它。

## 已完成：计划执行层与长期计划工作台

| 旧版能力 | 新版实现 | 验收入口 |
| --- | --- | --- |
| 计划、任务、标签的增删改查 | 服务端所有权校验和乐观锁；计划详情页提供标签和任务的新增、编辑、删除 | `计划` |
| 周计划和长计划浏览 | `GET /plans/{id}/tasks/page` 按日期范围分页；页面使用七日日期轨道 | `日程` |
| 休息日补做 | `POST /tasks/{id}/defer`；周末被标识为“休息日 / 可补做”，可在右侧面板安排补做 | `日程` |
| 任务状态、验收、计时、手动补时 | 状态/验收面板、开始暂停、补录实际分钟；全部写入用户私有数据 | `日程` |
| 日计划与实际的分页统计 | `GET /plans/{id}/stats/daily`；按日期服务端分页 | `统计` |
| 标签投入统计 | 按计划日期范围汇总标签、完成数、计划分钟和实际秒数 | `统计` |
| 固定 G1—G5 闸门 | 每个计划可自由新增、调整日期、记录验收证据的里程碑 | `计划 → 阶段与模板` |
| 任务模板 | 用户私有模板的增删改查；模板删除不会影响已生成任务 | `计划 → 阶段与模板` |
| 重复任务 | 每天、工作日、每周同一天，服务端生成独立可编辑的任务 | `计划 → 阶段与模板` |

## 后续对等项

1. **回收站和恢复**：软删除、定期清理与恢复接口，替代前端本地垃圾箱。
2. **复盘中心**：按日编辑、按范围浏览和导出；现有数据库实体与接口作为基础。
3. **计时流水**：按任务/日期/来源分页展示，并提供 CSV 导出。
4. **旧版辅助数据迁移**：把旧备份中的模板和闸门记录转换为新版模板、里程碑；当前原始 JSON 仍完整保留。

## 数据边界

- 客户端仅保存短期访问令牌；业务数据始终由 API 按当前登录用户隔离。
- 所有分页接口采用零基页码 `page`，页容量 `size` 上限为 100。
- 延期任务保留原计划日期，同时以 `deferTo` 作为补做日；同一任务在日程轨道上只出现一次。
