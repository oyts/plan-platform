# 受邀客户端测试

当前网页/API 与 Windows 为 0.1.7；Android 已验收接入包为 0.1.6 / 构建 11，0.1.7 / 构建 12 的应用内升级仍在真机验收中。官网可以使用网页版及下载 Windows 安装包；Android APK 不在官网或公开静态更新源发布，仅向受邀朋友提供接入包。公开注册仍关闭，不共享管理员账号。

## 邀请朋友

在网页版的“成员”页面，为每位朋友的邮箱创建普通成员邀请。将该人的专属注册链接单独发给本人；请勿把链接发到公开群、源码仓库或安装包说明中。朋友在 HTTPS 注册页自行设置密码，然后在网页、PC 和手机上登录同一个自己的账号。

服务器根地址统一使用 `https://plan.zijun701.cn`。不要填 `/api`、登录页路径或 `127.0.0.1` 测试端口。同一账号的周期计划、休息日、目标路线及今日待办从相同云端服务读取；不同账号的数据相互隔离。离线编辑先保存在本机队列，恢复网络后在同步中心处理；有冲突时需要本人选择，不会静默覆盖其他设备的新内容。

## Windows 安装

从 [计划舱官网](https://plan.zijun701.cn/) 点击“下载 Windows 安装包”。首次安装后确认服务器地址并登录受邀账号。正式更新源已启用，安装前由用户确认；自动下载默认关闭。仍使用旧测试签名 0.1.3 的客户端需要手动迁移，先妥善保留旧数据和离线队列。

Windows 安装包已验证长期更新签名，但没有受信任的 Authenticode 发布者证书，系统可能显示未知发布者。应核对来自官网的文件及哈希；不要关闭系统安全防护或绕过安全阻止。

## Android 安装

当前可分享的已验收接入包为 `PlanCabin-0.1.6-release.apk`，构建号必须为 11，不使用已撤回的构建号 10。这是正式长期签名包，不是 debug 或回归测试包。包名为 `cn.zijun701.plan.app`，支持 Android 7.0 及以上；长期 RSA 3072 位签名已通过 apksigner 验证。

文件 SHA256：

```text
eb390a34d6e6aed09f5c753a62f30e75a63454a54b366a7b970248df445d078e
```

传输后若文件不完整、哈希不符或手机拒绝签名，不继续安装，重新获取原文件。手机如需安装来源授权，仅由本人为实际使用的文件管理器允许本次安装，不关闭系统安全扫描。

首次登录使用自己的受邀账号。它与旧 `cn.zijun701.plan.mobile` 应用并存，不能覆盖旧测试包；旧包未同步队列不会自动迁移，不要为解决安装问题卸载旧包。云端已同步数据在新包登录后可读取。

0.1.6 / 11 开始使用需要登录的受限更新 API。登录自己的云端账号后，在客户端页面检查更新；自动下载默认关闭，安装需要本人及系统确认。未登录时不能获取 APK，官网仍不提供下载或二维码。切换服务器、退出账号或账号失效时，不能沿用上一账号的下载授权。

旧 0.1.4 / 0.1.5 尚未接入这个 API，可保存编辑后使用上述同包名、同签名的接入包覆盖一次，不卸载或清除数据。目标 0.1.7 尚未完成真机升级验收，不将候选包当作已验收版分享；最终发布状态见 [0.1.7 记录](release-017.md)。

## 三端验收建议

在自己的账号创建一条测试周期计划，PC 修改标题后，在网页与手机刷新核对。再创建一条目标路线和今日待办，分别从另外两端修改，确认各端显示一致。最后关闭重开客户端，检查保持登录、内容保留、同步队列及冲突状态。不要把 APK 文件与账号密码、邀请链接、签名密钥或备份口令一起分享。
