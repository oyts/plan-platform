# 云端账号原生登录联测

此验收让真实 Windows EXE、Android APK 和独立网页浏览器同时连接正式 HTTPS 云端，验证原生登录、三模式数据互通、会话重开、版本冲突和用户隔离。它与使用临时 H2 API 的原生业务回归分开，不以浏览器模拟原生请求，也不使用 USB 业务转发。

2026 年 10 月 15 日，0.1.8 的独立 Windows EXE、iQOO V2426A / Android 15 上的独立 APK 和正式网页完成 **10 项通过、0 失败**，新增四节互动教学、原生重开及各端进度保存。记录为 `acceptance-results/cloud-native/2026-10-15T04-27-37-579Z-03e2dc3a/report.json`。此流程不覆盖正式客户端；正式签名包升级另见 [0.1.8 发布记录](release-018.md)。

历史 0.1.4 真机截图曾显示日期输入框右侧文字轻微裁切；它属于当时的视觉观察，不据此判定 0.1.8 存在同样问题。此回归以业务和原生桥接验证为主，不替代专项视觉验收。

## 准备与运行

先完成 [正式网页验收](public-web-acceptance.md)，私有 `accounts.json` 中应已有两个受邀请的普通验收账号。脚本只接受此前指定的两个测试邮箱，并先核对登录响应中的 USER 角色；不读取管理员密码，不开放注册，不修改生产安全配置。

按当前源码构建 [独立原生回归包](native-regression.md)，并在手机安装生成的 `cn.zijun701.plan.mobile.regression`。不要使用旧版本测试包。关闭独立“计划舱回归测试”窗口，保留正式计划舱不动；连接一台手机、授权 USB 调试并保持解锁。已存在的测试进程、调试转发或占用端口会令前置检查失败，不会被脚本批量终止。

在项目根目录双击 `verify-cloud-native.bat`，或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/cloud-native-acceptance.ps1
```

本机使用已有 Chromium、Node 22 与 Android SDK。脚本会校验源码指纹、EXE 和 APK 哈希后，启动独立 PC 与手机测试客户端；不安装或卸载应用。实际业务请求分别经过 Rust 和 Java 桥接，TLS 校验保持开启。ADB 仅转发本机 WebView 调试端口，不为业务网络创建反向转发。

## 验收范围

1. 正式云端健康与版本、公开注册关闭、两个普通账号以及管理员接口拒绝访问。
2. Windows 和 Android 原生设置与登录正式域名，网页使用独立浏览器登录同一测试账号。
3. PC 创建周期计划和任务，手机与网页交叉修改，三端刷新后读取同一云端数据。
4. 原生编辑休息日配置，三端刷新一致，原任务保留。
5. 手机创建目标路线、阶段和指定前置步骤，PC 完成前置步骤后，网页与手机解锁后续步骤。
6. 手机新增今日待办、PC 编辑、网页完成，三端读取相同状态。
7. 关闭并重开真实 PC 与 Android 测试应用，原生会话恢复且三种业务数据仍可见。
8. PC 提交新版本后，手机使用过期快照操作，拒绝覆盖云端新值并回退勾选。
9. 原生退出并重开不自动恢复账号；切换第二个 USER 后，不显示第一个账号的数据和队列，后端拒绝跨用户读写。
10. 三端分别操作四节教学、保存并重开；进度保存在各端本地，不向真实业务写入教学案例。

新记录带“云端联测”及每轮唯一标记，所有业务写入只针对测试账号自己的合成记录。列表按标记筛选，不把已有记录的分页位置当作新增失败。重复运行保留历史合成数据，不自动删除账号或批量清理数据库。

## 结束与证据

结束后退出本轮测试会话、撤销脚本自己的辅助 API 会话，恢复独立客户端原来的服务器配置，停止本轮持有的测试进程并移除调试转发和锁。配置恢复使用真实原生命令，不需要原来的本地测试 API 仍在运行；不恢复登录令牌，也不触及正式客户端。

报告位于 `acceptance-results/cloud-native/latest.html`，每轮保留 `report.json` 和截图。Android WebView 不支持 CDP 截图时，仅在独立测试应用处于前台且不显示密码输入框时使用设备截图。邀请链接、密码、刷新 Cookie 和访问令牌不写入报告、截图或 Git；不生成 HAR/trace。

这项验收不验证正式签名安装包、跨版本升级、公开下载、支付或小程序。断网编辑和队列重放由独立 TCP 故障回归另行验证；本轮不切断手机全部网络，也不阻断公共云端服务。
