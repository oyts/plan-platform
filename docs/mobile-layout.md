# 手机布局优化与验收

本阶段优化 Spring Boot + Vue 3 多用户项目的手机页面，复用 Web、Android 和 Windows 的业务逻辑。没有修改服务器接口、数据库结构、离线队列协议或正式更新源，也没有部署阿里云。

## 布局与交互

沿用计划舱蓝白配色，使用瑞士式网格、细分隔线和清晰的文字层级。手机不再缩放桌面导航：

- 底部固定“今日、日程、计划、更多”四个入口，兼顾安全区域；统计、复盘、记录、导出、同步、设置等功能收进“更多”。原生客户端另有“客户端”入口，管理员另有“成员”入口。
- 今日页缩小日期与标题区域，完成数量、计划用时、实际用时并排显示；任务操作留在对应任务下方。
- 任务编辑在手机底部面板中进行，PC 使用右侧抽屉；点击编辑直接回显该任务，不跳到列表顶部。保存期间禁止重复提交，取消不修改原任务。
- 手机点选日程任务后立即打开详情面板，保留状态、验收、计时、补做与补录操作；PC 仍使用日程右侧详情栏。
- 计划任务列表增加标题/内容搜索、完成状态筛选和每页 10 项展示。这里是**前端展示分页**，不是新的服务端分页接口；仍复用原任务缓存与离线投影。
- 表单字号至少 16px，主要按钮触控高度至少 44px；面板支持滚动、关闭按钮、焦点管理和 Android 返回事件关闭。强制更新时仍限制业务入口，不绕过原更新规则。

竖屏断点为 700px；低高度、粗指针设备按手机横屏布局处理。桌面保留完整导航，窗口变窄时使用响应式布局。

## 代码入口

- `web/src/mobile.css`：手机视觉层级、横竖屏、底部导航与面板样式。
- `web/src/components/MobileNavigation.vue`：主导航、更多功能和账号退出。
- `web/src/components/AppSheet.vue`：共享原生 dialog 面板、焦点与滚动锁。
- `web/src/components/AppIcon.vue`：本地 SVG 图标，不增加远程图标依赖。
- `web/src/useMobileLayout.ts`：日程详情面板与桌面详情栏的切换。
- `web/src/views/PlanDetailView.vue`：任务搜索、筛选、分页和编辑抽屉。
- `web/src/views/ScheduleView.vue`：手机任务详情面板。

## 重跑与人工检查

先构建 Web，再在 `web` 目录执行 `npx playwright test`。可单独执行 `npx playwright test mobile-layout.spec.ts --project=mobile-web`。浏览器验收使用 43130/43131 与随机内存数据库。

真机先运行 `prepare-native-regression.bat`，再运行 `verify-native-clients.bat`；详见 [原生客户端自动化回归](native-regression.md)。回归使用独立包名和内存数据库，不覆盖正式 0.1.3 应用，不清除原账号、计划或待同步操作。

仍需人工体验软键盘弹出时的编辑与滚动、系统返回键、不同字体缩放和其他厂商手机。自动化的表单填写没有证明这些系统交互都已通过。下一步应先确认手机实际观感，再准备正式版本签名和应用内更新验收，不直接发布回归调试包。
