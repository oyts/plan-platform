# 计划舱UI重构输入与核心保护约定

本文服务于下一大阶段的界面、布局、Logo与图片重设计；当前只交接功能和状态，不实施新视觉。基线为已发布0.1.25、Android30、MySQL Flyway V34。第六阶段是否允许冻结，另看[综合回归进度](core-freeze-progress.md)，不能因交接材料齐全就跳过验收。

## 用户与管理员信息结构

周期计划处理确定周期、每天安排和休息日；目标路线处理没有固定结束时间、按空闲推进的阶段和依赖；今日待办记录当天零散事项。三模式的导航、位置、统计和回收站保持分离，公共工具不改变用户上次所处模式。

个人工具包括AI工作台、今日与提醒、日周复盘、编排与历史、私人模板库、数据中心、离线范围／冲突中心、教学、反馈和账号安全。管理员额外进入独立管理中心，分为总览、成员与邀请、AI资源与用量、运行与安全、反馈处理；必须保留返回个人工作区。管理员权限不提供读取他人私人计划、AI原文或备份的能力。

当前准确路由与视图见[源码路由清单](ui-route-inventory.json)，生成命令`node scripts/core-freeze-inventory.mjs`。`/members`和`/operations`继续兼容跳转；Web history URL与原生hash URL分别验证，不将路由静态检查当作后端权限证明。查询参数及必须保留的深链载荷见[结构化重构约定](ui-rebuild-contract.json)。

## 页面状态与关键行为

| 页面组 | 主要状态 | 重构不得破坏的行为 |
| --- | --- | --- |
| 周期计划、日程、执行面板 | 空、加载、休息日、未开始／进行中／完成、离线、409 | 周一至周日的自选休息日；任务／进度双版本；计时与历史不可被批量调整或AI重建 |
| 目标路线、阶段与步骤 | 空、暂停、阻塞依赖、自由／顺序、长列表、回收站 | 无截止日期和日更要求；后端完整依赖校验；归档、暂停、删除分开 |
| 今日待办 | 当日／历史、未完成／完成、查询、离线待提交 | 独立事项与分页；不能混入周期统计；陈旧勾选失败恢复原值 |
| AI工作台 | 需求、推荐、模式确认、等待／执行／一次修复、UNKNOWN、草稿／分批、预览、已应用、409 | 明确同意必要内容外发；不自动调用／创建；先完整预览再确认；旧草稿、保护项和后续队列保留 |
| 模板、数据中心、外部协作 | 选择／取消、只读预检、差异、确认、重复提交、失败 | 私有格式4及旧格式兼容；恢复新记录而非覆盖；协作材料不混成整账号备份 |
| 同步与离线范围 | 缓存未知／过期、待同步、冲突、失败、缺共同基础 | 24小时身份边界、顺序／幂等、人工同步；无共同基础不冒充三方合并 |
| 账号与验证 | 未登录、邀请有效／过期、密码确认、两邮箱待验证、撤销会话、离线不可用 | OS认证本人操作；验证链接不进入日志／统计；变更后重新登录，不删本机队列 |
| 管理中心 | 无权、无数据、采集陈旧、参数预览、保存409、邀请忙碌／回退链接 | 服务端角色和所有权；热配置不清计次；原始私密数据不进监控／邮件 |
| 更新、文件与系统提醒 | 可选／必更、忽略／稍后、拒装、系统授权／取消、后台受限 | 默认不自动下载；本人安装；签名／包身份／账号绑定；安全出口与原数据保留 |

空数据与未采集不能画成相同的零；失败或离线不能清除已输入内容。文字、触摸、键盘、横竖屏、安全区、大字体、长名称及分页均应有可达操作，不靠隐藏关键按钮解决布局拥挤。

## 数据身份与安全边界

UI变化不得更换正式应用包身份、证书、凭据命名空间或已有IndexedDB账号／服务器键。实体ID、版本、离线操作键、AI修订和原对象绑定均为业务契约，不因重绘页面重新生成。任何存储或协议升级必须独立设计可回滚兼容方案。

Web只缓存应用壳和明确访问的私有快照；原生会话由Windows凭据管理器／Android Keystore保护，本机业务缓存不因此变成加密数据库。AI、计时、账号安全不进入离线付费或安全操作重放。平台能力不完全相同：浏览器关闭后不保证提醒；Android受权限及厂商后台策略影响；Windows系统文件窗口可能需要本人选择路径。

更新偏好在浏览器存储中，极快强停／断电的落盘不作绝对保证；不能把这条边界扩展为允许丢业务队列。前五阶段已有的真实签名、非空合成队列升级、正式空队列、备份恢复证据按各自范围使用，不声称验证过任意设备或所有接收应用。

## 代表性设计资料与后续验收

[合成场景](ui-rebuild-synthetic-cases.json)提供规则周期、弹性吉他路线、独立待办、409双端差异、未完成AI批次、长内容和未知指标；它不是可导入备份，不含用户私人信息或有效账号。设计时可扩展同类合成样本，不上传真实对话、计划、邮箱或屏幕截图。

UI大重构需另立设计与实施计划。完成后以本次功能地图和核心链路重新验收，并增加全站视觉／可访问性及真实PC／Android大版本回归。核心功能冻结不等于1.0发布、公开注册、APP上架或完成备案，也不授权顺带开发团队、市场等非核心功能。
