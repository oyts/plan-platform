# 个人数据中心

数据中心已随0.1.15交付，日周复盘与格式3已随0.1.18发布。三种工作模式都可进入，不会切换当前模式。第五阶段的整套模板和格式4是未发布扩展，见[模板阶段记录](templates-progress.md)。

## 两种文件

可阅读 CSV 补齐目标路线、今日待办和周复盘；原有周期计划任务、统计、每日复盘和计时导出保留。CSV 对引号、换行以及空白后出现的公式起始符进行转义。

私有 JSON 使用 `format=plan-cabin-private-backup`，当前正式格式3、候选格式4，候选继续接受旧私有格式1—3。包含周期计划、休息日、标签、单任务模板、任务与进度、里程碑、已结算计时流水、原每日复盘、路线阶段与依赖、待办、三模式日周复盘及既有恢复副本。格式2增加稳定的任务开始证据，格式3增加日复盘和可选自述，格式4增加私人整套模板；旧文件不推测精力或增加投入意愿。归档和删除状态一并保留。只导出本人已同步数据，不会自动同步或清空本机队列。

文件不包含账号凭据、邀请、AI 对话、反馈、服务器配置、签名、本机草稿／队列或客户端偏好。正在运行但尚未结算的时长不估算，恢复为暂停。文件本身含私人计划和复盘正文，不是可公开上传的脱敏诊断；请自行保存到受保护的位置。

## 预检与恢复

选择文件只在本页内存读取，不自动上传。用户同意后，将文件发送到当前登录服务器进行只读预检；预检不建业务记录。服务器严格校验字段白名单、类型、引用、任务唯一进度、阶段归属、路线依赖环及大小限制，返回文件指纹、数量和警告。

核对后再次明确确认才恢复。所有 ID、所有权和关系重新映射，新记录属于当前账号，不覆盖任何现有计划、路线、待办、历史或队列。恢复批次与所有记录在同一事务提交；数据库约束失败整批回滚。相同文件指纹在同一账号重复恢复只返回原批次，同一操作编号换内容会被拒绝。网络中断后应保留原文件、联网原样重试，不要删除旧内容来解决问题。

模板名称会附带恢复标记，避免与当前账号已有模板的唯一名称冲突；过长显示名会缩短，完整原名另存在 `restored_original_name` 并继续包含在私有备份中，不截断任务标题或正文。日周复盘以保留原日期的只读副本保存在数据中心，不能覆盖当前复盘，也不擅自移动日期。需要继续写作时，可手动复制需要的文字。

每份文件上限 5 MiB、全部记录合计 20000 条、单路线 1000 步、单个列表 512 项（前置 ID 列表还受 4000 字符上限约束）。超限时应保留原数据，联系维护者规划分批迁移；不要清数据来凑限制。旧版 schemaVersion 1—6 迁移文件仍走原入口，本接口不能恢复其他软件任意格式。

## 接口与验收

`GET /api/data/backup` 导出；`POST /api/data/preview` 预检；`POST /api/data/restore` 确认恢复。`GET /api/data/restores`、`GET /api/data/restored-weekly-reviews`和`GET /api/data/restored-daily-reviews`分页读取本人批次和副本；`GET /api/data/export/{routes|todos|weekly|daily}`生成CSV。所有接口要求登录、响应no-store，不接受指定他人账号导出。

V21 仅新增恢复批次和周复盘副本表；不替代 MySQL／OSS 生产备份。定向验收使用隔离服务与合成账号，覆盖往返关系、中文与历史、已有内容保护、循环／越权引用拒绝、幂等并发和注入数据库故障后的整批回滚。MySQL 演练及原生设备门槛另记于 `roadmap-progress.md`。
