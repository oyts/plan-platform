## 到期与访问范围

旧客户端固定请求 `/client-updates/android/latest.json`，不带账号凭据，因此不能只给新鉴权接口加别名。本窗口仅开放这个清单和清单指定的单个原签名 APK；最低支持构建号为 1，升级保持可选，不修改客户端的自动下载偏好。

Nginx `secure_link` 在两个精确端点分别核对固定截止时间。过期后两个端点返回 404；即使客户端提前保存了清单，随后请求 APK 也会过期拒绝。截止时间不取自查询参数，不能通过修改 `expires` 参数延长；响应为 `Cache-Control: no-store`。规则无需 cron、模型唤醒或人工在线。已下载到设备的文件不因服务器关闭而消失。

APK 与清单放在既有 Web 只读挂载中的独立目录，通过精确文件 alias 服务。配置、脚本及目录列表不开放，没有对私有 Android 目录、密钥或数据库增加 alias。现有 Windows 文件和入口未修改；没有重建后端或变更数据库。
