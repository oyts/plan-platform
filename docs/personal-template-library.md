# 个人整套模板库

“更多 → 个人模板库”用于保存本人周期计划、目标路线或完整新建AI草稿的结构，再建立独立副本。已随0.1.19／Android24正式三端发布，实际验收范围见[发布记录](release-0119.md)；早期实现过程保留在[续做记录](templates-progress.md)。

## 保存和使用

选择本人未删除、未归档的来源，填写名称、说明、分类和收藏状态。先检查完整结构预览，再勾选确认。路线来源支持搜索和分页；AI来源须先在工作台独立保存完整草稿，不接受临时待办、处理中会话或已有对象调整草稿，不调用AI或扣次数。

模板是独立快照，来源后续修改或删除不影响模板。周期计划保留周期、休息日、标签、任务与里程碑；路线保留阶段、步骤、参考用时和依赖。预览按20项分页，参考总分钟不随分页变化，前置关系用步骤名称展示。

使用模板时重新命名；周期计划还需明确选择周期和每周休息日。任务与里程碑按起点等距平移，结束日期必须容纳全部内容。休息日只作标记，不自动移动或删除安排；目标路线不强加日期期限。

副本重新生成ID及关系映射，不复制完成状态、实际计时、执行备注、复盘、对话原文、通知授权或离线队列。资料编辑、重新取来源更新模板、删除模板都不修改来源和已有副本。

## 保护和限制

每人最多100份模板；每份各结构列表最多1000项、结构JSON最多256KiB，完整私有备份仍受5MiB限制。不提供公共市场、公开分享、跨账号协作或待办模板。

写入要求联网、本机存储可用和空同步队列；不会清空或代为提交队列。来源表单按服务器与账号保存在本机；未保存资料编辑有离开提醒。确认后先保存原请求及操作编号，结果未知时由用户原样重试，同编号不重复创建，不自动重放。放弃重试记录前须先核对结果。

模板版本和来源结构变化后返回409并保留输入，不覆盖其他端改动。复制和应用记录原子提交，约束失败整批回滚。所有接口只查询本人数据，响应不缓存。

## 接口与备份

新整套模板使用 `/api/structure-templates`，旧单任务模板 `/api/templates` 不变。

| 操作 | 接口 |
| --- | --- |
| 查询、读取完整结构 | `GET /api/structure-templates`、`GET /api/structure-templates/{id}` |
| 保存预览、确认保存 | `POST /api/structure-templates/capture/preview`、`POST /api/structure-templates/capture` |
| 资料编辑、删除 | `PUT /api/structure-templates/{id}`、`DELETE /api/structure-templates/{id}?version=...` |
| 副本预览、确认建立 | `POST /api/structure-templates/{id}/preview`、`POST /api/structure-templates/{id}/apply` |

V28新增模板及操作防重表。私有备份格式为4，继续接受1—3；旧文件不含整套模板。嵌套结构同样校验字段、类型、引用、依赖环和大小，不接受执行字段。恢复产生本人新模板ID，不覆盖内容，不恢复旧操作记录；重复恢复幂等。旧客户端不保证可读格式4，导入请使用支持该格式的新版本。
